# Mold Maker

Complemento de Blender (4.2 a 5.x) para **crear moldes imprimibles de cualquier pieza**: molde rígido de
2 mitades (resina, escayola) o caja para silicona. Todo en modo Objeto y la pieza original no se toca.

- **Rígido**: partición automática por la parte más ancha, llaves de centrado, bebedero y respiraderos.
- **Silicona**: caja + base con ranura y soporte (que hace de bebedero). Calcula la silicona necesaria.
- Calcula los ml de material y exporta las piezas a STL en mm.

Instalar: Editar → Preferencias → Complementos → Instalar desde disco → `mold_maker-1.0.1.zip`.
Guía completa en `mold_maker/LEEME.md`.
